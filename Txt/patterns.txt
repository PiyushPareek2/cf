# Kadane = DP (Quick Revision)

## 1. DP means

Define a **state** + write a **transition**.

---

## 2. Kadane State

```text
dp[i] = Maximum subarray sum ending at index i.
```

**"Ending at i"** is the key idea.

---

## 3. Transition

Only two choices:

* Start a new subarray.
* Extend the previous one.

```text
dp[i] = max(nums[i], dp[i-1] + nums[i])
```

---

## 4. Space Optimization

Since `dp[i]` only depends on `dp[i-1]`:

```cpp
cur = max(nums[i], cur + nums[i]);
ans = max(ans, cur);
```

No DP array needed.

---

# Maximum Product Subarray

State:

```text
maxProd[i] = Maximum product ending at i
minProd[i] = Minimum product ending at i
```

Need `minProd` because:

```text
(-) × (-) = (+)
```

Transition:

```text
maxProd =
max(
    x,
    prevMax * x,
    prevMin * x
)

minProd =
min(
    x,
    prevMax * x,
    prevMin * x
)
```

---

# General Kadane DP Pattern

```text
State:
dp[i] = Best answer ending at i

Transition:
dp[i] = Best(
    Start New,
    Extend Previous
)

Optimization:
If only dp[i-1] is needed,
replace the DP array with one variable.
```

---

# Recognize Kadane-like DP

If a problem asks for the **best value ending at the current index**, think:

* ✅ Maximum Sum
* ✅ Maximum Product
* ✅ Maximum Absolute Sum
* ✅ Some Stock DP states
* ✅ Many 1D DP problems

---

## One-line Memory Trick

> **Kadane is just 1D DP where the state is "best answer ending here," and since it depends only on the previous state, we compress the DP array into one variable.**
