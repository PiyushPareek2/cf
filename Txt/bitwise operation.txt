For interviews, LeetCode, and Codeforces, most bit manipulation problems are combinations of a small number of patterns.

# 1. Check if kth bit is set

```cpp
if (n & (1 << k))
```

Example:

```cpp
n = 13; //1101
k = 2
```

Bit 2 is set.

---

# 2. Set kth bit

```cpp
n |= (1 << k);
```

Example:

```cpp
1010
set bit 0
=1011
```

---

# 3. Clear kth bit

```cpp
n &= ~(1 << k);
```

Example:

```cpp
1011
clear bit 1
=1001
```

---

# 4. Toggle kth bit

```cpp
n ^= (1 << k);
```

Example:

```cpp
1011
toggle bit 1
=1001
```

---

# 5. Remove lowest set bit

```cpp
n &= (n - 1);
```

Example:

```cpp
110100
110011
------
110000
```

Uses:

* Count set bits
* Power of 2 check

---

# 6. Is power of 2

```cpp
n > 0 && (n & (n - 1)) == 0
```

Examples:

```cpp
1
2
4
8
16
```

Only one bit set.

---

# 7. Extract lowest set bit

```cpp
n & (-n)
```

Example:

```cpp
110100
001100 (two's complement trick)
=000100
```

Uses:

* Fenwick Tree
* Bitmask DP

---

# 8. Count set bits

Built-in:

```cpp
__builtin_popcount(n);
__builtin_popcountll(n);
```

Manual:

```cpp
while(n){
    cnt++;
    n &= (n-1);
}
```

Complexity:

```cpp
O(number of set bits)
```

---

# 9. Count trailing zeros

Built-in:

```cpp
__builtin_ctz(n);
__builtin_ctzll(n);
```

Example:

```cpp
101000
```

Answer:

```cpp
3
```

---

# 10. Count leading zeros

```cpp
__builtin_clz(n);
__builtin_clzll(n);
```

Useful for:

* Highest set bit
* Log2 calculations

---

# 11. Find highest set bit

```cpp
31 - __builtin_clz(n)
```

For long long:

```cpp
63 - __builtin_clzll(n)
```

---

# 12. Check odd/even

```cpp
n & 1
```

Odd:

```cpp
1
```

Even:

```cpp
0
```

# 13. Divide by 2

```cpp
n >> 1
```

---

# 14. Multiply by 2

```cpp
n << 1
```

# 15. Generate all subsets (Bitmask)

```cpp
for(int mask=0; mask<(1<<n); mask++)
{
    for(int i=0;i<n;i++)
    {
        if(mask&(1<<i))
        {
            // take ith element
        }
    }
}
```

Complexity:

```cpp
O(n * 2^n)
```

Very common.

---

# 16. Iterate all submasks

One of the most important CF patterns.

```cpp
for(int sub=mask; sub; sub=(sub-1)&mask)
{
}
```

Complexity:

```cpp
O(3^n)
```

Used in:

* SOS DP
* Bitmask DP

---

# 17. XOR properties

```cpp
a ^ a = 0
a ^ 0 = a
```

and

```cpp
a ^ b ^ a = b
```

Uses:

* Single number problems
* Missing number problems

---

# 18. Find unique element when others appear twice

```cpp
int ans = 0;
for(int x : nums)
    ans ^= x;
```

---

# 19. Swap without temp

Rarely useful today.

```cpp
a ^= b;
b ^= a;
a ^= b;
```

---

# 20. Missing number

```cpp
ans = 0;

for(int i=0;i<=n;i++)
    ans ^= i;

for(int x:nums)
    ans ^= x;
```

---

# 21. Prefix XOR pattern

Like prefix sums.

```cpp
pref[i]=pref[i-1]^a[i];
```

Range XOR:

```cpp
pref[r]^pref[l-1]
```

---

# 22. XOR Basis (Linear Basis)

Advanced CF pattern.

Used for:

* Maximum XOR subset
* kth XOR
* Distinct XOR values

Rating range:

* 1800–2500+

---

# 23. Bitmask DP

State:

```cpp
dp[mask]
```

Examples:

* Traveling Salesman
* Assignment Problem
* Matchings

Typical constraints:

```cpp
n ≤ 20
```

---

# 24. SOS DP

Transform:

```cpp
for(int i=0;i<n;i++)
{
    for(int mask=0;mask<(1<<n);mask++)
    {
        if(mask&(1<<i))
            dp[mask]+=dp[mask^(1<<i)];
    }
}
```

Very important around CF 1800+.

---

# 25. Enumerate subsets of fixed size

```cpp
__builtin_popcount(mask)==k
```

---

# 26. Binary Trie

Used for:

* Maximum XOR pair
* Maximum XOR subarray
* XOR queries

Common in:

* LeetCode Hard
* CF 1700+

# The patterns you should absolutely know

If your goal is LeetCode 1800+ / CF Specialist → Expert, master these first:

1. Check/set/clear/toggle bit
2. `n&(n-1)`
3. `n&(-n)`
4. Popcount
5. Power of 2
6. XOR properties
7. Prefix XOR
8. Generate subsets
9. Iterate submasks
10. Bitmask DP
11. Binary Trie
12. XOR Basis

Those 12 cover roughly **90%+ of bit-manipulation questions** you'll encounter before advanced competitive programming topics.
